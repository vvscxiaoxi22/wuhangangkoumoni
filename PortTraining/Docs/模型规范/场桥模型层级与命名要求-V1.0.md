# 场桥模型层级与命名要求 V1.0

| 项目 | 内容 |
| --- | --- |
| 适用设备 | 青岛港新八绳 MAX 场桥 |
| 用途 | 发给模型工程师，作为场桥模型拆分、命名和交付要求 |
| 目标引擎 | Unity 6000.0.42f1 / URP |
| 坐标约定 | Y 向上；X 为小车运行方向；Z 为大车运行方向 |

> 本文件只规定模型拆分、层级和名称。准确尺寸、外形及八绳走向以最终确认的图纸和参考资料为准。

## 一、简单制作要求

- 按真实尺寸 1:1 制作，统一使用米。
- 门架、小车、卷筒 A、卷筒 B、吊具上架和吊具必须独立拆分，不能合并成一个整体模型。
- 卷筒、小车车轮、吊具锁销和导板等需要运动的部件，轴心放在真实旋转或运动中心。
- 吊具上架与吊具本体必须分开，导入 Unity 后当前共用一个组合刚体。
- 不制作固定钢丝绳网格；只提供 8 个出绳点、8 个固定端和 8 个上架滑轮中心点，运行时绳索由 Unity 生成。
- 可见模型与碰撞模型分开；碰撞模型使用简单几何体。
- 所有对象保持 Scale = 1，避免负缩放；名称只使用英文、数字和下划线。

## 二、模型层级与名称

```text
YC_ModelRoot                         # 场桥模型交付根节点
├─ YC_GantryModel                    # 门架和大车主体模型
│  ├─ Gantry_Structure               # 门腿、主梁、联系梁等钢结构
│  ├─ Gantry_TravelUnits             # 大车行走台车、车轮和外壳
│  ├─ Gantry_StairsPlatforms         # 楼梯、走道和检修平台
│  ├─ Gantry_Handrails               # 栏杆和防护结构
│  ├─ Gantry_Cabinets                # 电气柜和设备箱体
│  └─ Gantry_LightsSigns             # 灯具、标识和设备编号牌
├─ YC_TrolleyModel                   # 随小车横移的模型
│  ├─ Trolley_Frame                  # 小车车架主体
│  ├─ Trolley_Wheels                 # 小车行走轮
│  ├─ Trolley_FixedSheaves           # 小车顶部固定导向滑轮
│  └─ RopeDeadEnds                   # 八个钢丝绳固定端空节点组
│     ├─ Loop01_DeadEnd ... Loop04_DeadEnd
│     └─ Loop05_DeadEnd ... Loop08_DeadEnd
├─ YC_DrumA_Model                    # A组起升卷筒模型
│  ├─ Drum_A                         # 卷筒、轴和外观机构
│  └─ RopeExits                      # L01-L04四个出绳点空节点
│     └─ Loop01_Exit ... Loop04_Exit
├─ YC_DrumB_Model                    # B组起升卷筒模型
│  ├─ Drum_B                         # 卷筒、轴和外观机构
│  └─ RopeExits                      # L05-L08四个出绳点空节点
│     └─ Loop05_Exit ... Loop08_Exit
├─ YC_HeadblockModel                 # 吊具上架模型
│  ├─ Headblock_Frame                # 上架主体结构
│  ├─ Headblock_Sheaves              # 上架滑轮可见模型
│  ├─ Headblock_Actuators            # 新八绳MAX微动推杆模型
│  └─ RopeSheaves                    # 八个上架滑轮中心空节点
│     ├─ Loop01_Sheave ... Loop04_Sheave
│     └─ Loop05_Sheave ... Loop08_Sheave
├─ YC_SpreaderModel                  # 集装箱吊具模型
│  ├─ Spreader_Frame                 # 吊具主体框架
│  ├─ Telescope_EndA                 # A端伸缩梁
│  ├─ Telescope_EndB                 # B端伸缩梁
│  ├─ Twistlock_FL                   # 前左锁销
│  ├─ Twistlock_FR                   # 前右锁销
│  ├─ Twistlock_RL                   # 后左锁销
│  ├─ Twistlock_RR                   # 后右锁销
│  ├─ Guide_FL / Guide_FR            # 前侧两块导板
│  ├─ Guide_RL / Guide_RR            # 后侧两块导板
│  ├─ MiddleLock_EndA / EndB         # 双20尺中锁机构
│  └─ ContainerAttach_LOC            # 集装箱连接中心空节点
├─ YC_OperatorCabModel               # 本地驾驶室模型
│  ├─ Cab_Exterior                   # 司机室外壳
│  ├─ Cab_Interior                   # 司机室内部和操控台
│  ├─ Cab_Glass                      # 司机室玻璃
│  └─ DriverEye_LOC                  # 驾驶员视角空节点
└─ YC_CollisionModel                 # 单独交付的简化碰撞模型
   ├─ COL_Gantry                     # 门架碰撞体
   ├─ COL_Trolley                    # 小车碰撞体
   ├─ COL_Headblock                  # 吊具上架碰撞体
   └─ COL_Spreader                   # 吊具碰撞体
```

中文备注只用于说明“这里应放什么模型”。模型节点仍使用英文名称；`Loop*_Exit`、`Loop*_DeadEnd`、`Loop*_Sheave`和`*_LOC`都是空节点，不放网格。

## 三、导入 Unity 后的放置位置

| 模型节点 | 放入 Unity 层级 |
| --- | --- |
| `YC_GantryModel` | `10_GantryMotion/Visual` |
| `YC_TrolleyModel` | `20_TrolleyMotion/Visual` |
| `YC_DrumA_Model` | `20_TrolleyMotion/Hoist/Drum_A/Visual` |
| `YC_DrumB_Model` | `20_TrolleyMotion/Hoist/Drum_B/Visual` |
| `YC_HeadblockModel` | `30_SpreaderPhysics/Headblock/Visual` |
| `YC_SpreaderModel` | `30_SpreaderPhysics/35_Spreader/Visual` |
| `YC_OperatorCabModel` | 按实机归属放入门架或小车的 `Visual` |
| `YC_CollisionModel` | 由 Unity 开发人员拆入对应 `Physics/Colliders` |

## 四、命名解释

| 名称 | 含义 |
| --- | --- |
| `YC` | 场桥 Yard Crane |
| `LOC` | Unity使用的空节点、连接点或定位点 |
| `COL` | 简化碰撞模型，不参与正常渲染 |
| `Loop01`至`Loop08` | 新八绳MAX的8条绳索回路编号 |
| `FL / FR / RL / RR` | 前左 / 前右 / 后左 / 后右拓扑标签 |
| `EndA / EndB` | 吊具两端；实际现场方向待图纸确认 |

## 五、关键轴心要求

| 对象 | 轴心位置与动作 |
| --- | --- |
| `YC_GantryModel` | 原点放在设备地面基准和大车轴线参考点 |
| `YC_TrolleyModel` | 原点放在小车轨道中心参考点，沿 X 轴移动 |
| `Drum_A / Drum_B` | 轴心放在各自卷筒旋转轴中心 |
| `YC_HeadblockModel` | 原点放在吊具上架工程中心 |
| `YC_SpreaderModel` | 原点放在吊具中心线和锁销平面参考点 |
| `Twistlock_* / Guide_*` | 轴心放在真实旋转轴或铰接位置 |

## 六、交付文件

交付 `YC_Gantry_V01.fbx`、`YC_Trolley_V01.fbx`、`YC_Headblock_V01.fbx`、`YC_Spreader_V01.fbx`和`YC_Collision_V01.fbx`，同时提供3ds Max、Maya或Blender源文件及PBR贴图。未确认的尺寸、方向或结构统一标记为 `DRAFT`，不要自行补定。
