本矩阵把场桥灰盒的核心动作转换为可重复执行、可明确判定、可保留证据的验收项。它定义的是验收标准，不代表所有动作已经形成正式业务闭环。

## 2. 闭环判定规则

一个动作只有同时满足以下条件，才能标记为“操作闭环已实现”：

1. **入口存在**：键盘、操控台或`equipment.action`能够发起动作。
2. **前置条件受控**：设备状态、安全条件和互斥条件在执行前检查。
3. **执行唯一**：同一动作不会被重复执行；正式接口按`operationRunId + actionId`幂等。
4. **成功可确认**：有明确状态变化和成功回执，不依赖目测。
5. **失败可确认**：拒绝、超时或安全禁止有原因码，且原状态不被破坏。
6. **反馈可观察**：位置、速度、锁销、着箱、连接状态和安全状态可被读取。
7. **结果可留证**：日志包含版本、输入、关键数值、结果和关联标识。
8. **可恢复**：拒绝后可修正重试；故障后进入安全状态；重启不会伪造成功。

当前场景执行链以v16为状态机基线，后续已加入v17 Standalone输入、大车/鸣笛/夹轮器、低空防碰/HUD、控制电源/急停/显式故障复位、大车/小车锚定、吊具泵/尺寸及旋转逻辑。v23已把吊具旋转角度投影到模型、碰撞体、传感器和挂箱节点，并取得Harness、Unity程序集编译和Play初始化绑定证据；但只有v16及更早物理链具有本文引用的完整Play回归，v23实际非零旋转/回零及30吨组合回归仍不能标记“已验证”。整个场景仍未接入统一`PortTraining.Contracts`的Named Pipe传输、跨进程持久去重、结果持久化和重启恢复，因此不能称为港口实训平台正式工单闭环。

## 3. 状态标签

| 标签 | 含义 |
| --- | --- |
| `已实现/已验证` | 当前代码存在，且已有Unity Play运行证据 |
| `部分实现` | 动作存在，但缺少日志、失败回执、正式状态或运行验证 |
| `未实现` | 当前代码没有对应入口或闭环逻辑 |
| `开发者专用` | 只能用于灰盒调试，不得作为正式训练动作 |

## 4. 通用验收前置条件

- 场景只有一个`YC_RuntimeRoot`和一个`YardCraneEightRopeMaxPrototypeRig`。
- 启动日志中的`model`与`profile`必须与本文档一致。
- 必须依次出现`YC_EIGHT_ROPE_MAX_READY`和`YC_EIGHT_ROPE_MAX_PRETENSIONED`。
- 自动空载回归必须出现`YC_EIGHT_ROPE_MAX_PASS`，不得出现`YC_EIGHT_ROPE_MAX_FAIL`。
- 8条回路、16段可视绳腿和所有附件必须绑定完成，状态不得出现NaN或Infinity。
- 30吨测试箱使用`containerGrossMassKg=30000`；允许范围为`2200～40500kg`。
- 每个手动用例开始前只允许在空载、静止且非预张紧/载荷交接阶段按`R`安全复位；不满足条件必须输出拒绝日志且状态保持不变。
- 验收日志必须保留完整时间顺序，不能只截取单条PASS。

## 7. 推荐执行顺序

### 7.1 正常全流程

1. 启动场景，取得`READY → PRETENSIONED → PASS`。
2. 空载执行一次A/D启动和停车，再执行一次W/S起升和停车。
3. 执行YC-ACT-13吊具左右旋转、松手停止、自动回零和手动打断；确认模型与逻辑角度一致。
4. 在未对准状态请求锁箱，确认`LOCK_REJECTED`且状态不变。
5. 下降对箱并锁箱，确认`LOCKED → LOAD_TRANSFER_READY locked=True`。
6. 带箱执行小角度旋转并回零，确认箱体、碰撞和传感节点同步且八绳物理门槛不被破坏。
7. 在净空不足时请求横移，确认小车不动。
8. 起升到安全净空，确认`COLLIDER_RESTORED`，松键并等待`SETTLED`。
9. 左右各完成一次横移和停车，确认存在可控惯性且指标不超限。
10. 回到目标箱位，下降至落箱高度。
11. 在尚未落稳时请求解锁，确认`UNLOCK_REJECTED`。
12. 落稳后解锁，确认`UNLOCKED → LOAD_TRANSFER_READY locked=False`。
13. 空吊具再次起升，确认箱体不再跟随且质量恢复空载。
14. 结束用例后执行调试复位，等待重新预张紧。

### 7.2 任一用例立即失败条件

- 出现`YC_EIGHT_ROPE_MAX_FAIL`、`YC_LOADED_HOIST_SETTLE_TIMEOUT`、NaN、Infinity或未处理异常。
- 锁箱/解锁拒绝后状态发生改变。
- 低净空时小车仍移动，或悬空/运动中成功解锁。
- 绳索锚点不随小车、上架或卷筒运动。
- 吊具—箱体组合出现持续上下抖动、穿透、弹飞或非预期瞬移。
- 为通过用例而放宽`8mm`、`0.35m`、`1.5°`、锁箱或落箱门槛。
