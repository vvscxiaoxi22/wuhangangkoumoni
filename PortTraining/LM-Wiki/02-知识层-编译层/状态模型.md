# 状态模型

本文件是状态模型摘要，字段、消息和迁移接口以[跨软件接口与参数标准V1.1](跨软件接口与参数标准-v1.1.md)为准。

> 2026-09-02校正：`SafeHold`的安全条件重新满足只代表“允许申请复位”，不得自动恢复运行；必须收到操作者新的显式故障复位请求并通过全部互锁检查。

## 任务模板

```text
Draft → Validated → Published → Retired
```

已发布模板不能原地覆盖；修改生成新`taskVersion`。

## 工单

```text
Queued → Available → Preflight → Starting → Running
                                   ↓          ↓
                                Terminated  Paused
                                              ↓
                                           Running
Running → Completed / Terminated → Archived
Queued / Available → Cancelled → Archived
```

关键规则：

- 学生端没有人工`Accepted`状态；`deliveryAck`只表示工单已经自动缓存。
- 外部场景未返回`Ready`前不得进入`Running`。
- 同一工位同一时间只能有一个活动运行。
- 完成、终止和取消必须持久化，重启后不得回退。
- 状态迁移必须携带`expectedVersion`并在单事务中完成。
- 工单状态由Authority根据运行事件投影，客户端不得维护第二份权威状态。

## 训练运行

```text
Created → AcquiringLease → Launching → Ready → Running → Finalizing
                                          ↓       ↓          ↓
                                        Failed  Paused   Completed / Terminated / Failed
                                                  ↓
                                               Running
```

每次尝试使用新的`operationRunId`。终态、安全回执、结果和outbox通过`finalization`单事务提交；同ID不同结果进入冲突审计。

## 联合作业

```text
WaitingForParticipants
→ ParticipantsReady
→ InProgress
→ WaitingForHandover
→ HandoverConfirmed
→ Completed
```

任意非终态可进入`Paused`或`Terminated`。岸桥或场桥单个子工单完成不等于全局作业完成。

## Gateway控制租约

```text
Available → Reserved → Active → SafeHold → Releasing → Available
                         ↓           ↓
                      Faulted     Faulted
```

- 租约绑定`leaseId + leaseEpoch + operationRunId + stationId + sceneInstanceId + controlMode`。
- 同一工位只能有一个`Reserved`或`Active`租约。
- 学生端所有者心跳、场景心跳任一超时，或者PLC掉线、急停、点表错误、控制方式变化时必须进入SafeHold并清零运动输出。
- 进入`Starting`后Local/Remote模式锁定，运行中不得切换。

## 场桥场景作业执行阶段

场景进程生命周期继续由`YardCraneSceneStateMachine`管理；以下状态只描述一次活动运行中的机构执行阶段，两者不得合并成第二套工单权威状态。

```text
WaitingForRun
→ Initializing
→ PreTensioning
→ ReadyEmpty / AlignedEmpty / MovingEmpty
→ LockPending
→ LoadTransfer
→ ReadyLoaded / HoistingLoaded / TrolleyTravelLoaded
→ LandingConfirmed
→ UnlockPending
→ LoadTransfer
→ ReadyEmpty
```

任一非终态在PLC离线、实时输入达到`250ms`危险阈值、所有者/协调器心跳超时、租约或控制方式不匹配、急停或控制电源异常时进入`SafeHold`；机构内部故障进入`Faulted`。

- 作业执行权绑定`operationRunId + leaseId + leaseEpoch + sceneInstanceId + stationId + controlMode`，任一字段变化都不能沿用旧授权。
- 每次Named Pipe握手接受一个新的`streamId`，新流从独立序号重新开始；旧流和倒退序号不得改变机构输入。
- `100ms≤dataAgeMs<250ms`可继续消费但质量标记为`Stale`并告警；`dataAgeMs≥250ms`必须清零运动输出并进入`SafeHold`。
- `SafeHold`复位必须仍属于同一运行和租约、控制方式一致、PLC在线、急停释放、控制电源正常、机构静止且所有手柄回中，并收到操作者在条件恢复后发出的新显式故障复位请求；禁止仅因条件恢复而自动退出`SafeHold`。复位后只接受新鲜后续帧，不恢复或回放进入`SafeHold`前的运动指令。
- `equipment.action`按`operationRunId + actionId`幂等。第一次拒绝的动作重复到达仍保持拒绝语义；相同ID改变动作或目标进入`ACTION_ID_CONFLICT`。
- 场景内存只保存当前运行的执行缓存和反馈，不是工单或结果权威存储；Gateway/NodeService负责跨进程去重保留、事件归档和最终状态提交。
