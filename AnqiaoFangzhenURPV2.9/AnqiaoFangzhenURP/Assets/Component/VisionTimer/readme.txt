
   一个简单好用的计时器，总共三个c#脚本，一个用于在Unity编辑器查看计时器状态，一个用于管理计时器，一个计时器handle，用于查询计时器各种属性

   计时器使用对象池且可以设置对象池大小 ，所以运行时开销很小。

    管理器提供创建计时器、取消计时器（放入池子）、暂停（或所有）计时器 、重启（或所有）计时器、
    销毁计时器、计时器激活数量、清空（放入）对象池等方法，计时器回调方法也可传入任意参数。

     handle提供id、启动时间、（上}下一次执行时间、执行数次、剩余次数、要执行总次数、
     是否无限执行、是否运行（暂停）、距上（下）次执行时间间隔、运行（暂停）总时长、是否忽略时间缩放等属性，提供取消、销毁方法。

=================================================================================================================================

在创建计时器之前可以设置对象池大小：
	EasyTimer.PoolVolume = number 	->默认为200 
	创建计时器后调整将无效

创建计时器：
	EasyTimer.CreateTimer(float 首次延迟,
				int 总执行数,
				float 第二次后延迟
				,Callback 回调方法，
				object 参数)

	此方法有多个重载函数，根据自身情况初始化计时器，创建后会在 hierarchy面板创建[timer]游戏对象，可以点击查看各计时器handle的属性
	计时器执行完毕后会自动放入对象池，这个方法回返回一个 TimerHandle 类型的计时器 handle，用于查询此handle的各种属性
	
	EasyTimer类也提供一些方法用于管理计时器

	计时器默认受到时间缩放影响,如果希望创建一个不受时间缩放影响的计时器，只需要在创建计时器后再调用EgnoreTimeScale(true)方法

	如：    EasyTimer.CreateTimer(3,()=>{print("tick")}).EgnoreTimeScale(true)

	如果传入多参数到回调方法，可以用数组来代替
