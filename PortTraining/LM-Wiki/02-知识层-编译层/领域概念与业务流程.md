# 领域概念与业务流程

装卸船、车道、AGV、双学生机和六个运行单元的完整关系见[项目开发基线（2026-08-28）](项目开发基线-2026-08-28.md)。

## 核心概念

- 工单：教师端、TOS或本地节点下发的作业定义。
- 任务实例：某学生在某工位执行工单形成的状态实例。
- 训练运行：一次实际进入驾驶场景的执行过程，使用唯一`operationRunId`。
- 自由练习：不占用正式工单，但必须拥有独立训练运行实例。
- 联合作业：岸桥、AGV、场桥共享同一个`operationId`完成交接。
- 训练档案：由已提交的训练结果账本生成，不能由UI直接拼接假数据。
- 学生画像：对训练结果的聚合，不作为第二份不可恢复的事实源。

## 标准业务流程

```text
任务进入收件箱
→ 学生选择任务
→ 创建任务实例与operationRunId
→ Gateway取得控制租约
→ 启动操作场景
→ 场景Ready
→ Running
→ Completed或Terminated
→ 幂等写入结果账本
→ 更新工单、训练档案和学生画像
→ 释放控制租约
```

自由练习必须从“创建独立训练运行”开始，不能复用当前正式工单上下文。
