## 3. 原型内已验证的闭环

- 教师新增任务、发布 → 同标签页切换学生 → 直接进入 → 暂停、错误与显式复位 → 完成 → 保存 → 刷新后档案可读。
- 草稿编辑 → 参数拒绝 → 修正发布 → 撤回取消 / 确认 → 学生不再展示撤回工单。
- 自由练习生成独立演示工单；终止保存与重练的新运行ID，不把未保存尝试计入档案。
- PLC格式错误拒绝；保存设置不宣称连接；TOS样例外部ID+版本去重；考核一期置灰。
- 1440×1000与1080×1920驾驶HUD下边界小于视口50%，中心/下半屏无准星或对位框。390px管理页无页面级横向溢出。
- 两组浏览器脚本12+9分组PASS，覆盖记录身份过滤、CSV下载、损坏缓存拒绝及显式清除。WebMCP只验证替身契约，未验证原生环境。
- 岸桥发布可配置五种V1.1名称的导板工况及一只40/20尺或两只有序20尺箱；配置随任务详情、学生运行和历史记录快照传递。旧缓存可读但缺少配置的岸桥任务不可直接启动，只有显式复制、补全和发布才生成新版本，旧工单与历史记录不被改写。

5. 获得原型确认后移植到Unity UI Toolkit，沿用已有只读快照适配器与动作回执；不要把浏览器演示值接入真实设备。
