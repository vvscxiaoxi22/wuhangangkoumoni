## 1. 状态判定规则

| 状态 | 判定条件 |
| --- | --- |
| `已实现` | 入口、执行、成功/失败回执、持久化、异常恢复均已形成可验证闭环 |
| `部分实现` | 已有真实代码或可运行子能力，但仍缺执行方、跨进程回执、持久化、恢复或正式联调中的一项及以上 |
| `未实现` | 只有规划、接口文档、静态/交互原型，或代码仍是明确占位实现 |
| `一期不开放` | 已由项目范围明确推迟，不作为一期可操作功能交付 |

本表按实际逻辑判断，不以类名、按钮名称、注释、测试名称或页面效果替代验收证据。

## 2. 总体结论

当前已经形成两套Unity工程和一套教师端交互原型：

1. `PortTraining`学生端Unity工程：登录、工作台、任务中心、训练档案、本地模拟设备状态和本地JSON数据能力已具备，整体为`部分实现`。
2. `YardCraneSimulator`场桥Unity工程：`StudentHome`三入口已通过`Bootstrap`进入同一`YardCrane`运行场景并按来源返回；学习训练目标跟踪、开放自由练习和10分钟本地考核已接通。绳索当前已在源码中改为v30的8根独立直绳，但只完成代码与编译验证，尚未完成Unity Play、画面重复绳排查、静力平衡及30吨物理回归，整体仍为`部分实现`。本地考核只生成非正式审计，不产生平台成绩。
3. `teacher-prototype`教师端：已有可点击Web原型，但没有真实服务、数据库、发布同步和监控链路，业务功能为`未实现`。

平台级完整生命周期仍未闭环。目前尚不能完成“教师真实发布 → 学生同步 → 启动独立场景EXE → S7直连控制 → 场景提交结果 → NodeService持久化 → 教师查看结果”的端到端作业。

### 4.2 当前需要特别说明的实现边界

- `S7PlcTransport.Connect()`当前明确抛出`NotSupportedException`，因此真实S7通信是`未实现`。
- `EmbeddedGatewayClient`只能作为模拟输入和接口原型，不能作为最终生产架构。
- “进入驾驶室”和“自由练习”当前只发出C#事件，没有外部EXE执行方，因此不能标记为`已实现`。
- 上一条仅指`PortTraining`平台学生端的外部场景启动链。`YardCraneSimulator`工程内部的`StudentHome`已能从学习训练、自由练习和任务考核三个入口实际进入`Bootstrap → YardCrane`并返回，但这是同一Unity工程内的本地闭环，不能替代独立EXE Launcher、RunTicket、平台任务下发或正式成绩链。
- 本地训练记录与画像可以落盘，但尚未接到真实场景结果；现阶段不应生成或展示演示假成绩冒充真实训练数据。

## 9. 后续开发优先级

### 9.1 2026-09-01优先级决策

`YardCraneSimulator`是当前最高优先级和核心交付物。先把它做成不依赖学生端、教师端、NodeService和PLC也能独立运行的场桥全流程模拟器；平台接入与真实PLC接入在该闭环稳定后实施。

必须同时满足两种输入路径：

```text
键盘 / Xbox手柄 ─┐
                  ├→ 统一操作语义 → 作业授权与安全联锁 → 机构运动命令 → 场桥物理与反馈
S7安全适配器 ───┘
```

运动控制不得直接读取键盘键值、Xbox按键或PLC地址。输入适配器只负责产生统一操作语义；作业状态机负责判断动作是否允许；机构控制器只执行通过联锁后的运动命令。接PLC时由`YardCraneS7Integration`安全适配器产生统一操作语义，不重写场桥运动和业务流程。

#### P0.4 场桥四类全流程任务

按以下顺序形成可玩的闭环：

1. **卸船转堆MVP**：海侧AGV/内集卡到位 → 对位 → 着箱锁定 → 带载起升 → 大车/小车转运 → 目标箱位落箱 → 解锁 → 车辆/任务状态完成。
2. **装船出堆**：堆场目标箱位抓箱 → 海侧车辆作业位放箱 → 交接完成。
3. **陆侧收箱**：外集卡到位 → 抓箱 → 指定堆场箱位落箱 → 车辆离场。
4. **陆侧提箱**：指定堆场箱位抓箱 → 外集卡放箱 → 交接完成。

每类任务都必须包含任务开始、目标提示、车辆到位、抓放箱条件、错误操作拒绝、完成/失败反馈、本地结果记录和一键重新开始。

## 12. 2026-09-11 StudentHome三模式本地闭环更正

### 12.1 已形成的本地运行链

1. `StudentHome`的学习训练、自由练习和任务考核三个入口均创建不可变训练会话上下文，经`Bootstrap`进入同一个`YardCrane`运行场景；启动失败会撤销本次会话并恢复入口页。
