# PortTraining 项目协作规则

开始任何开发、审查或文档任务前，必须先阅读：

1. `LM-Wiki/README.md`
2. `LM-Wiki/03-规则层/AGENTS.md`
3. `LM-Wiki/02-知识层-编译层/跨软件接口与参数标准-v1.1.md`
4. 当天的 `Docs/讨论记录/YYYY-MM-DD.md`（存在时）

每个任务必须严格执行`实现完成 → 验证通过 → 文档更新 → 任务交付`。代码可编译不等于验证通过；验证未通过或文档未更新时，不得宣称任务完成。详细交付字段遵循`LM-Wiki/03-规则层/任务验证与文档交付规范.md`。

完成项目讨论、代码变更、架构决策或问题审查后，必须更新当天的讨论记录，并留下可供其他智能体复验的命令、环境、结果和日志证据。

不得把尚未接通的事件、模拟数据或静态页面描述为“功能已完成”。只有具备入口、执行、成功/失败回执、状态持久化和恢复路径时，才能称为操作闭环。
