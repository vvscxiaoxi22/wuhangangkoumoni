# 港口实训统一界面交互原型 V1.1

- 日期：2026-09-06
- 状态：核心浏览器交互已验证；不是整套产品交付，也不是所有原型细节已实现。
- 工作区：teacher-prototype，沿用现有 React / Vinext 项目；本次不修改 Unity 运动、输入、PLC 或 UI Toolkit 代码。
- 本机预览：http://localhost:3000/
- 运行：在本目录执行 npm run dev。
- 数据边界：浏览器单标签页的临时演示状态。不得作为正式学生账号、工单库、成绩库或多机同步服务。请只使用演示身份。

## 设计与入口

共用深蓝 / 海蓝基底、青色动作按钮、白色文字、圆角半透明面板和背景模糊。引用用户原型的主题配色，并复用项目已有蓝色港口插画。岸桥、场桥共用应用壳；教师和学生共用视觉，不共用全部功能权限。浏览器内的身份切换是演示，不是身份认证。

登录 → 选择机型和身份 → 工作台 → 任务 / 训练项目 → 独立全屏驾驶原型 → 保存演示结果 → 成绩档案。

教师新增 → 配置目标、箱型、车道、车辆、源 / 目标位置、对象和操控方式；岸桥额外配置导板工况及单箱 / 双20尺箱组 → 草稿 / 校验发布 → 同一标签页退出并切换学生身份 → 工单直接进入。无人工接收环节。

## 已实现的原型行为

- 学生 / 教师与 QC / YC 共用登录、首页、底部状态栏、任务中心、记录、设备设置及原型导览。
- 六类训练目录：单项、联动、作业、能力提升、故障排除、自由练习。
- 场桥收 / 发箱，20/40尺，1–5车道；岸桥装 / 卸船、俯仰、20/40/双20尺、1–9车道。参数仅为原型选项，不是设备限位认证。
- 岸桥任务可选择`按作业流程 / 全部抬起 / 全部放下 / 海侧工况 / 陆侧工况`，并配置一只40/20尺箱或两只有序的20尺箱；双箱箱号去空格后不区分大小写判重，质量要求正整数kg。详情、驾驶操作指引和训练记录复用发布时快照，均标明“工单配置 · 非设备反馈”。
- 教师任务新增、草稿编辑、发布校验、已发布工单复制、撤回、草稿 / 已撤回任务删除确认；历史结果持有独立工单快照。
- 学生直接进入工单；自由练习独立生成演示工单；开始后本地 / ROCS 无切换入口。
- 全屏驾驶原型的5秒倒计时、参数 / 锁箱 / 制动状态、演示步骤、暂停 / 继续、联锁错误、显式复位、终止确认、结束详情、重练、结果保存。
- 计时只在 running 阶段推进；重练新建运行ID；未保存重练不计入档案；完成 / 终止分开统计。
- 档案按演示身份、机型、项目、日期过滤，详情包含事件，支持CSV下载；不生成虚构分数，导出标注 Unscored / 原型演示并保护CSV公式注入。
- TOS内置样例生成教学草稿，按示例外部编号 + 版本去重，不连接真实TOS。
- PLC配置格式校验及本机原型设置保存；明确未连接PLC，不把格式校验写成连接成功。
- 缓存格式错误时阻止写入，不静默覆盖；只有再次确认后才清空本原型键。不可承诺多标签并发一致性、跨电脑同步或生产级持久化。
- 原生 dialog 承担焦点管理、关闭、确认；横屏、1080×1920竖屏与窄屏管理页完成关键检查。

## 保留的边界与未完成项

1. 尚未移植到 Unity UI Toolkit；没有正式登录、Authority/Edge、进程握手、控制租约、S7、TOS或真实Xbox输入。
2. 驾驶画面来自原型中的单张低分辨率参考图，显示参数和步骤为显式UI演示；不代表实际运动、重力、绳索反馈或多个真实摄像头。
3. 教学监控使用真实的“未接入”状态，远程暂停 / 终止按钮置灰；数字孪生是区域选择 / 参考图与业务入口，不是实时三维孪生。
4. 考核中心保持一期不开放。导览中的设计预览只说明未来结构，不实现考试发布、评分规则、权威计分。
5. 故障原型重复八行同一供电案例，不足以形成八套完整排故资料；原理图 / 故障位置图明确显示待补齐，诊断笔记仅在当前资料弹窗会话保留。
6. 岸桥导板实际开闭方向、Twin20与正式`isoCode`、场景锚点和吊具能力的精确绑定，各能力提升项目的完整场景参数、ROCS多摄像头视图仍待补齐，不能将原型字段或目录存在称为全量功能完成。
7. 当前WebMCP具有读状态 / 导航两项功能检测注册；已用浏览器契约替身验证，未在原生支持的注册环境验收。
8. 已询问是否更新现有私有在线原型，尚未收到发布选择。因此没有推送、提交站点版本、修改线上站点或把旧在线网址当作本版成果；本机预览保留。
9. 本次网页验证不改变09-05 Unity StudentEntry白块验证失败状态。
