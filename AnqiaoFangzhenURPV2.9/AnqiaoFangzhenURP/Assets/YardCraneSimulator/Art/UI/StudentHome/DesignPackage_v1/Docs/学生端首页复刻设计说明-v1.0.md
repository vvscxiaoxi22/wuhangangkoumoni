# 学生端首页（模式选择）复刻设计说明 v1.0

## 1. 页面身份与范围

- 场景：`StudentHome`。
- 显示：Display1，单屏设计分辨率 `1920×1080`。
- 页面：登录成功后的学生模式选择首页。
- Display2 不在本次改造范围；继续由 `StudentSideLower.uxml/.uss` 管理。
- 视觉基准：`Reference/student-home-reference-v1.png`，必须按其布局复刻，不增加侧边栏、统计面板、设备状态大卡片或多图拼接。

## 2. 信息架构

页面只保留五层：

1. 港口背景图和统一蓝色遮罩。
2. 顶部品牌、身份面包屑、英文页面标识、返回和退出。
3. 页面标题“模式选择”和一行学员问候语。
4. 三张核心模式卡：学习训练、自由练习、任务考核。
5. 底部两组克制的编辑性文字。

## 4. 背景与遮罩

- 背景使用 `Background/student-home-background-v1.png`，全屏 `scale-and-crop`，不得拉伸。
- 在背景上叠加 `Layout/background-vignette.svg` 的等效遮罩；若 UI Toolkit 不直接支持 SVG，则用两个绝对定位的半透明渐变层复刻。
- 背景整体不透明度保持 100%，遮罩提供色调统一，不得像旧版一样用 55% 背景透明度导致画面发灰。
- 禁止在页面中央增加大面积雾化白层，港口灯光、水面和起重机轮廓需要保持可见。

## 5. 顶部区域

### 5.1 数字双生胶囊

- 素材：`Layout/brand-pill.svg`。
- 文案：`数字双生`。
- 字号 20 px，Semibold，白色 `#F4FBFF`，水平垂直居中。
- 胶囊只有一个，不增加产品 Logo 或额外图标。

### 5.2 面包屑导航

- 底图：`Layout/top-navigation.svg`。
- 从左到右：`{学员姓名}`、`·`、`场桥司机`、`·`、`模式选择`。
- 当前项“模式选择”使用青色 `#6FE6F5`；其余使用 `rgba(231,244,255,0.72)`。
- 右端英文：`YARD CRANE  /  TRAINING MODE`，字距 4 px，字号 12 px，透明度约 55%。
- 身份数据来自现有 `identity` 标签，不在 UXML 中写死真实姓名或学号。

### 5.3 返回与退出

- `logout-button` 使用 `Icons/icon-back.svg` 的视觉；行为保持返回登录页并清理本地会话。
- `quit-button` 使用 `Icons/icon-close.svg` 的视觉；行为保持现有退出逻辑。
- 两者都是 58×58 圆形，间距 30 px，不显示“返回/关闭”文字。

## 6. 标题区域

- 英文眉题：`YARD CRANE  /  TRAINING MODE`，14 px，字距 5 px，颜色 `#6FE6F5`。
- 主标题：`模式选择`，64 px，Semibold，白色 `#F7FBFF`，行高 76 px。
- 副标题：`{学员姓名}，准备开始新一次作业？`，22 px，颜色 `rgba(225,239,252,0.66)`。
- 三行均水平居中；不要使用阴影描边或过重发光。

## 7. 模式卡统一结构

每张卡都是一个完整按钮，内部节点顺序固定：

1. 编号。
2. 英文名称。
3. 透明主图标。
4. 54 px 短分隔线。
5. 中文标题。
6. 两行说明。
7. 右下角圆形箭头。

卡片规格：

- 尺寸 `360×468`，圆角 28 px。
- 普通态使用 `Layout/mode-card-normal.svg` 的等效填充：深蓝玻璃、1.5 px 浅蓝描边。
- 悬停态可参考 `Layout/mode-card-selected.svg` 的等效填充：蓝青渐变、2 px 高亮描边、柔和外发光；不得把该效果作为任一卡片的永久初始状态。
- 不允许使用纯色实心卡片，也不允许把整张参考图切成三个按钮背景。
- 内边距：左/右 40 px，上 30 px，下 32 px。

## 8. 卡片内部尺寸

- 编号：32 px，颜色 `#72D9F2`。
- 英文：12 px，字距 3.5 px，颜色 `rgba(204,228,245,0.68)`。
- 主图标显示区域：约 `190×170`，水平居中；PNG 自身透明背景，不再套方形图标底框。
- 短分隔线：54×2 px，距图标下方 18 px。
- 中文标题：32 px，Semibold，白色。
- 说明文字：18 px，行高 28 px，颜色 `rgba(224,239,250,0.70)`。
- 箭头按钮：66×66；普通态用 `icon-arrow-normal.svg`，悬停/按下反馈可参考 `icon-arrow-selected.svg`。

## 9. 交互状态

| 状态 | 卡片表现 | 箭头表现 |
|---|---|---|
| Default | 普通深蓝玻璃 | 普通箭头 |
| Hover | 描边亮度提高、背景轻微变亮 | 选中箭头 |
| Focus | 不保持独立选中外观；当前三张主卡不抢占键盘焦点 | 普通箭头 |
| Pressed | 整体亮度降低约 8%，不缩放 | 维持选中箭头 |
| Disabled | 仅用于真正不可操作状态；透明度 45% | 普通箭头低透明度 |

进入首页时，三张卡都只能具备基础 `mode-card` 类，不给自由练习或其他卡增加 `mode-card-selected`。鼠标悬停任一卡时只临时展示统一 Hover，移开后立即恢复普通态。

## 10. 底部编辑性文字

- 左下：先放 126×2 px 横线，再放 `PRACTICE  EXPLORE  IMPROVE  TO BE A BETTER OPERATOR`。
- 右下三行：`DIGITAL TWIN` / `SMART PORT` / `BETTER TOMORROW`，右对齐，并在下方加入约 26 px 短线。
- 字号 11–12 px，字距 3 px，透明度 45%–60%；它们不能抢过主卡片。
- 旧版键盘/Xbox检测信息和启动状态不要常驻右下角；`launch-status`只在有提示或错误时，以中央卡片下方的一行轻提示出现。

## 11. 图标导入设置

三枚 PNG 主图标建议：

- Texture Type：Default 或 Sprite (2D and UI)，按现有 UI Toolkit 资源用法统一。
- Alpha Source：Input Texture Alpha。
- Alpha Is Transparency：开启。
- Wrap Mode：Clamp。
- Filter Mode：Bilinear。
- Max Size：512。
- Compression：None 或 High Quality，避免透明边缘出现黑边。
- Preserve Aspect：开启，显示时不得裁切、拉伸。

## 12. 必须保留的现有代码契约

- 保留 `student-home-page`、`identity`、`greeting`、`launch-status`。
- 保留 `learning-mode-button`、`launch-button`、`assessment-mode-button`、`logout-button`、`quit-button` 的名称，避免破坏 `YardCraneStudentSideShell.BuildUpperInterface()` 查询和事件绑定。
- 不修改登录交接、Bootstrap 启动、Display2、训练中心和场桥物理代码。
- 不建立新的 `StudentHome` 并行页面；应删除或隐藏 UXML 中已经废弃的旧工作台结构，但修改前需确认没有 C# 查询这些 legacy 节点。
- 所有首页按钮不得在 Play 时产生 `NullReferenceException`；缺少素材时应显示明确错误或安全降级，不得让整个 Shell 构建失败。
