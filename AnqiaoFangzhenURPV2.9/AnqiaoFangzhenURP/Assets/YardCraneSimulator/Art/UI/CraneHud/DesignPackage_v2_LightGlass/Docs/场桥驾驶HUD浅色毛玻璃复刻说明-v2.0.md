# 场桥驾驶 HUD 浅色毛玻璃复刻说明 v2.0

> 2026-09-15更正：本文原有Gateway接入约束已退出当前场桥PLC交付路径。HUD与`YardCrane`场景仍不得直接连接PLC或认识DB地址；唯一允许直连的位置是独立`YardCraneS7Integration`场景，详见LM-Wiki中的《场桥S7直连接入架构决策》。

## 1. 页面身份与实现边界

- 场景：`Bootstrap` 驾驶画面。
- 显示：优先 Display1，设计基准 `1920×1080`；在项目的 `1920×2160` 双屏堆叠模式中只占上半屏。
- 参考图：`Reference/crane-hud-light-reference-v2.png`。
- 核心原则：四周承载信息，驾驶视野中央完全留空；所有状态必须来自现有运行状态，不允许为了复刻效果图写死业务数据。
- 本包负责 HUD 视觉元素。背景驾驶画面由 Unity 相机实时渲染，`Reference/cockpit-background-reference.png` 只用于对照，不得作为运行时静态背景覆盖场景。

## 4. 视觉规格

### 4.1 玻璃面板

- 主底色：冰蓝白 `rgba(226, 244, 255, 0.78)`。
- 次级底色：`rgba(212, 235, 251, 0.68)`。
- 描边：1.5 px，`rgba(255, 255, 255, 0.72)`。
- 文字主色：深海军蓝 `#173E78`。
- 文字次色：`rgba(23, 62, 120, 0.72)`。
- 圆角：主面板 22–28 px；状态条 22 px；状态选择胶囊 18 px。
- 阴影/发光只做轻微层次，不允许恢复旧版深蓝黑底、强霓虹边框或大面积不透明卡片。

UI Toolkit 不支持实时背景模糊时，以半透明冰蓝填充、白色细描边和轻微内高光模拟，不安装额外包。Unity 6000.0.42f1 的 USS 不支持网页 CSS `box-shadow`；外发光必须用显式的 UXML 嵌套 halo 层、半透明背景与描边实现，也不得使用已确认不支持的`:last-child`结构伪类。

### 4.2 字体层级

- 项目标题：`单项操作 · {项目名}`，30–34 px，Semibold。
- 用时数值：30–34 px，Semibold；“用时”16–18 px。
- 面板行标签：17–20 px；数值 18–22 px，Semibold。
- 状态灯标签：15–17 px。
- 使用工程现有中文字体回退；缺字体时安全降级，不得导致 UIDocument 构建失败。

### 4.3 圆灯颜色

| 状态 | 亮态中心色 | 灭态 |
|---|---|---|
| 制动 | `#FFB128` 橙黄 | 灰蓝低亮度 |
| 锁定 | `#F02E3F` 红 | 灰蓝低亮度 |
| 开锁 | `#31D65B` 绿 | 灰蓝低亮度 |
| 单箱 | `#F2F5FA` 银白 | 灰蓝低亮度 |
| 双箱 | `#173F7F` 深蓝 | 灰蓝低亮度 |

亮态由实心圆、内高光、外圈和柔和发光组成；灭态仍应保留边框，不得完全消失。

## 5. 信息与运行数据映射

### 5.1 左侧六项遥测

按固定顺序展示：

1. `大车位置`：Gantry Position，单位 m。
2. `大车速度`：Gantry Velocity，单位 m/s。
3. `小车位置`：Trolley Position，单位 m。
4. `小车速度`：Trolley Velocity，单位 m/s。
5. `吊具高度`：Spreader/Headblock Height，单位 m。
6. `吊具速度`：Hoist/Spreader Vertical Velocity，单位 m/s。

数值统一保留两位小数。数据过期、缺失或非有限值时显示 `—`，绝不能继续显示最后一次数值并伪装为实时数据。

### 5.2 顶部任务标题

- Managed任务：显示`任务训练 · {状态/项目名}`。
- StudentHome创建本地会话且`YardCraneLocalTrainingNavigationBridge`存在：显示`自由练习 · {状态/项目名}`。
- 直接Standalone启动：显示`单机训练 · {状态/项目名}`；直接EditorDevelopment启动：显示`本机调试 · {状态/项目名}`。
- 仅凭`LaunchMode`不能推断为自由练习；必须由本地会话桥接器显式声明，避免调试/平台任务被错误标注。
- 安全告警不得占用任务标题。告警应使用现有紧凑提示条/状态类，且不能遮挡驾驶中心视野。

### 5.3 五状态灯业务规则

- `着箱`：只有 HUD 数据就绪且`SpreaderContact`为真时亮，离箱、锁箱后或数据断流时灭。该信号表示吊具对箱接触，不得与载箱放回目标位置后的`Landed`或大车`BrakeApplied`混用。
- `锁定` 与 `开锁`：互斥。`Locked` 时仅锁定亮；明确处于未锁状态时仅开锁亮；`Locking/Unlocking` 过渡时使用闪烁或警示类，但不得两灯同时常亮。
- `单箱` 与 `双箱`：互斥，取自吊具规格/当前模式。无法获得模式时两者均灭，并显示未知语义。

参考效果图中灯色只用于定义视觉，不代表运行时可以同时显示矛盾状态。

### 5.4 右侧当前任务

三行固定为：

- `当前任务：{任务名}`
- `目标箱号：{箱号}`
- `放箱地址：{地址}`

任务业务尚未接入时，值统一显示 `等待任务` / `—`，不写死“装船作业、XKSZ01、0302090”。一旦任务模型提供数据，必须由 Presenter/Adapter 注入，不允许 UI 主动轮询场景对象或自行推断。

### 5.5 右侧吊具姿态

三行固定为：

- `吊具左右倾转`
- `吊具前后倾转`
- `吊具水平回转`

如果现有状态只提供水平回转，则前两项显示 `—°`，水平回转显示真实角度。不能用同一个角度复制填满三行。

### 5.6 锁销条

- `已锁` 与 `未锁` 必须互斥。
- 已锁：青色亮点和浅蓝选中胶囊落在“已锁”。
- 未锁：选中胶囊落在“未锁”。
- 锁定/开锁过渡：胶囊可隐藏或显示“锁定中/开锁中”，沿用现有状态文字，不得瞬间跳成终态。

## 6. 交互契约

- 返回和退出必须由同一导航所有者把能力与实际执行函数原子绑定；HUD不能只发一个无人订阅的事件，也不能根据启动模式猜测能力。
- 没有执行方时按钮保持可见但禁用，并显示具体原因。Managed协调器未接入时显示平台导航未接入；直接Editor提示从Unity停止Play；直接Standalone没有首页可返且退出流程未接入。
- StudentHome本地自由练习由`YardCraneLocalTrainingNavigationBridge`同时绑定返回与退出。返回必须先终止当前运行、保留身份到Rig保存结束，再销毁Bootstrap/HUD并进入StudentHome；退出也必须先写终止状态，不能绕过保存。
- 解绑必须携带原所有者并匹配成功，旧桥接器不得清除新会话的导航执行器。
- `操作指引` 可以保留为小型非侵入入口；默认不展开，不在参考布局之外常驻大面板。
- 生命周期结果卡、断流提示、安全联锁提示等现有功能必须保留，只重做视觉，不删除行为。
- 运行结束结果必须区分`Completed / Terminated / Failed`。中途返回或退出可以留下审计记录，但不得按默认100分进入学生正式成绩索引；只有`Completed`可以计入成绩档案。

## 7. 分辨率与双屏规则

- 设计基准为 `1920×1080`。
- `1920×2160` 双屏纵向堆叠时，HUD 根节点固定为上半屏逻辑高度 1080，不得纵向拉伸到两块屏幕。
- 其他 16:9 分辨率等比缩放；超宽屏保持中央驾驶净空并锚定两侧面板。
- 宽度不足时允许收窄左右面板，但不得把它们移到画面中央。

## 8. 代码边界

- 保留现有 `OperatorHud.uxml` 节点 ID、Presenter/Adapter 数据通道、10 Hz 刷新节流、数据过期判断和生命周期结果逻辑。
- UI 只消费 `YardCraneHudState`（或现有等价状态）；禁止 UI 层主动读取场景对象、Rigidbody、PLC 或输入设备。
- HUD和`YardCrane`正式场景不得直连S7 PLC；PLC原始数据只允许由独立`YardCraneS7Integration`场景读取并经过安全适配后进入状态模型。
- 不安装 `com.unity.vectorgraphics`。本包 SVG 是视觉源，运行时可用 UXML/USS 等效绘制。

## 11. 七类独立提示框扩展（2026-09-10）

### 11.1 类型与互斥

最新效果图对应七类提示框：任务提示、倒计时、提示信息（确定/取消）、错误提示、任务完成、考核详情、成绩提交。全部是同一个 `prompt-layer` 下的独立视图，默认隐藏，任一时刻只允许一个视图显示。新提示替换旧提示时必须先解除旧按钮和倒计时回调，避免连续任务时误触上一轮动作。

生命周期进入 `Finalizing / ExitAllowed / Terminated / Failed` 时，旧提示和旧回调必须自动失效，真实终态优先。若任务协调器需要显示本轮任务完成弹窗，应在终态转换后使用本轮冻结结果重新触发，不能沿用转换前的窗口。

| --- | ---: | ---: | ---: | ---: |
| 任务提示 | 47 | 17 | 766 | 368 |
| 倒计时 | 873 | 18 | 339 | 362 |
| 提示信息 | 1265 | 46 | 599 | 314 |
| 错误提示 | 187 | 404 | 740 | 277 |
| 任务完成 | 991 | 397 | 741 | 293 |
| 考核详情 | 59 | 706 | 1042 | 356 |
| 成绩提交 | 1138 | 707 | 725 | 355 |

这些是 1920×1080 上屏逻辑坐标。1920×2160 组合屏中 Y 不得超过 1080；窗口出现时保留中央吊具与目标箱视野。为了避免半透明叠字，七类提示出现期间暂停显示常驻计时、任务条、状态灯、左右信息卡、导航按钮、指引入口和旧结果卡，关闭后统一恢复。

提示层在上屏内采用模态指针命中：点在窗口外也不会穿透到背后的 HUD 控件。该规则不截获键盘、Xbox、PLC 命令或物理更新，也不等价于暂停作业；需要阻止机构运动时必须由安全/任务协调器负责。

### 11.3 视觉规则

- 常驻 HUD 继续使用浅色冰蓝毛玻璃；弹窗单独使用深海蓝半透明玻璃、青色细边和白色正文，不能反向污染常驻样式。
- 普通动作按钮使用亮蓝填充；错误提示只在图标、边框和“我知道了”按钮使用警示红，不把整屏染红。
- 图标由 `Painter2D` 绘制，避免字体图标缺字；关闭按钮是每个弹窗自己的独立命中区。
- 当前视觉不依赖浏览器 CSS 的 `box-shadow`、`:last-child` 或 `:has()`。

### 11.4 数据与触发

- 任务提示：任务说明、目标箱号、放箱地址及左右 Bay 格位高亮由任务服务注入。
- 倒计时：只显示本轮剩余秒数并在归零时发出一次回调，不控制运动或安全状态。
- 提示信息：确定和取消是独立回调；回调前先关闭当前提示。
- 错误提示：确认只用于已读，不代表故障已经复位。
- 任务完成：时长和得分可为空；没有正式评分时显示 `—`。
- 考核详情：展示项目、时长、总分和扣分明细，不在 UI 内重新计算分数。
- 成绩提交：无提交执行器或缺少姓名/学号时禁用；发出请求后等待平台回执，不先声称成功。身份默认只读。

提示信息右上角 X 与“取消”使用同一回调；错误提示右上角 X 与“我知道了”使用同一已读回调。其他窗口的 X 只负责关闭。考核详情的表体必须是真正可命中的纵向 `ScrollView`，不能因为全局 HUD 透传设置而失去滚轮/滚动条交互。

UI 仍是只读展示和操作意图层，不读取 Rigidbody、输入设备、PLC 或 S7。正式协调器接入时应补充 `promptId`、`operationRunId`、`revision/requestId` 与成功/拒绝回执。

## 12. 七类提示框统一居中更正（2026-09-10）

用户明确要求 HUD 驾驶界面的所有弹窗居中显示。本节取代第11.2节的分散坐标和“弹窗保留中央驾驶视线”要求；常驻 HUD 在没有弹窗时仍保持四周布局与中央净空。

- 七类提示统一以 1920×1080 上屏中心 `(960, 540)` 为视觉中心，宽高继续沿用第11.2节，不因居中而拉伸或改变内容结构。
- `prompt-layer`负责水平、垂直居中，七个提示视图不再各自保存左上、右上、左下或右下坐标。由于同一时刻只显示一个提示，不会产生多个弹窗相互挤压。
- 1920×2160 双屏时居中基准仍是上方 Display1，而不是整个2160像素高度的中心；弹窗不得进入下方屏幕。1920×1080单屏回退使用同一中心。
- 弹窗继续保持模态指针命中、互斥触发、独立回调、关闭恢复常驻HUD和生命周期终态优先等既有规则。

## 13. 弹窗覆盖时保留常驻 HUD（2026-09-10）

本节取代第11.2节“提示期间暂停显示常驻HUD”和第12节“关闭后恢复常驻HUD”的旧规则。新视觉层级必须按下列顺序理解：驾驶画面在底层，完整浅色常驻HUD在中层，半透明遮罩与当前唯一弹窗在上层。

- 遮罩继续使用当前轻量半透明深色，不把背景完全盖住；常驻HUD不得设置`display:none`、`visibility:hidden`或通过透明度降为不可辨认。弹窗本身继续保持1920×1080上屏中心`(960, 540)`，1920×2160双屏时不得进入Display2。

## 14. 正式 `YardCrane` 场景与深海蓝皮肤更正（2026-09-10）
