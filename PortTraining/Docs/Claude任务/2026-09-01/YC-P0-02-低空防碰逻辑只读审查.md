# YC-P0-02低空防碰逻辑只读审查

## 1. 任务身份

- 任务编号：`YC-P0-02-CLEARANCE-REVIEW-01`
- 任务名称：未锁箱低空靠近集装箱时的大车/小车防碰逻辑审查
- 执行模式：只读审查
- 当前版本：`2026-09-01-eight-rope-max-v18-gantry-drive`
- 主控：Codex
- 执行代理：Claude Code

## 2. 背景与已知现象

- 用户可观察现象：吊具未锁箱、低空使用大车经过独立站立集装箱上方时，吊具与箱体接触后明显倾斜并接近翻转。
- 已有运行证据：三轮人工验证记录位于当天讨论记录第8节；最新一轮没有出现`YC_GANTRY_INHIBITED_CLEARANCE`，用户仍感觉行为不正确。
- 当前代码状态：已经加入统一接近判断、0.55m水平半径和只拦截驶向箱体方向的点积判断，但没有形成可证明正确性的诊断证据或自动化测试。
- 历史尝试：4.75m半径导致整轴锁死；缩小到0.55m后解除锁死；随后增加方向性放行撤离，但危险工况是否被识别仍不明确。

## 3. 本次目标

- 只读分析当前人工大车和小车路径中，集装箱对位误差更新、接近区判断、请求方向判断和输入清零的完整调用链。
- 找出可能导致“实际接近箱体但不触发保护”或“保护指标与真实碰撞几何不一致”的真实代码问题。
- 评估0.55m水平半径和0.35m垂直条件的物理含义，判断是否错误地将中心对位容差当成外形碰撞安全距离。
- 提出最小诊断方案：HUD/日志应暴露哪些原始量、派生量、方向点积和最终判定。
- 提出可自动化验证的纯逻辑提取边界和最小测试矩阵，但不得修改代码。
- 明确不做：不修改任何文件，不调整参数，不启动Unity，不声称问题已修复。
