# PortTraining LM-Wiki

LM-Wiki是港口实训平台的项目知识库，采用三层结构：

```text
01-原始资料层
    ↓ 整理、验证、去重
02-知识层（编译层）
    ↓ 转化为工程约束
03-规则层
```

## 三层职责

### 01 原始资料层

保存未经二次解释的事实、历史和运行证据。原始资料不应被知识层文档反向覆盖。

### 02 知识层（编译层）

把需求、代码、问题记录和客户反馈整理成用户、产品和研发可以直接使用的知识。

### 03 规则层

把已经确认的知识转化为开发、测试、提交和发布约束。

## 更新规则

- 每次项目讨论更新当天的`Docs/讨论记录/YYYY-MM-DD.md`。
- 需求发生变化时，先记录原始变更，再更新受影响的知识层文档。
- 架构决策必须写明背景、选择、替代方案、后果和生效日期。
- Bug关闭时必须保留触发条件、根因、修复范围和回归用例。
- 发布前必须执行规则层的发布检查表，不以“编译成功”代替功能验收。
